# Coverage Category Reports

Create one detailed report per in-scope category using `category-template.md`. The standard review category set is:

1. Cross-blueprint integrity
2. Sources
3. Business Use Cases
4. Required Capabilities
5. Quality Controls
6. Operational Capabilities
7. Data Products
8. Consumers
9. Data Flows
10. Technologies
11. Architecture Decision Records
12. High-Level Architecture

If a category is genuinely outside the declared review scope, document the exclusion rather than creating an artificial zero score.
