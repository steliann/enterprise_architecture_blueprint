# Refreshing an Existing Review

1. Validate the new Blueprint snapshot.
2. Compare Blueprint version/date and changed records.
3. Reassess affected coverage categories.
4. Re-evaluate existing Candidate/Active Gaps before creating new IDs.
5. Preserve stable gap/recommendation identifiers.
6. Use `absorbed`, `superseded` or `rejected` states rather than deleting historic review knowledge.
7. Update registers and integrated review counts.
8. Validate the Review.
9. Regenerate Word/slides from the refreshed Review.
10. Keep the previous packaged review as history when the user wants versioned evidence.
