# Refresh and Merge Rules

## Change classes

- **Confirm** — new evidence increases confidence without changing meaning.
- **Enrich** — adds detail without changing the concept boundary.
- **Correct** — replaces an inaccurate statement.
- **Supersede** — a new target or decision replaces an earlier one.
- **Split** — one record contains multiple distinct concepts.
- **Merge** — several records represent the same concept.
- **Deprecate** — the concept is no longer active but remains historically relevant.
- **Add** — genuinely new concept.
- **Conflict** — evidence cannot yet be reconciled.

## Stable IDs

Never renumber records to close gaps. Keep redirect or supersession metadata when merging. Deprecate files rather than deleting them when external references may exist.

## Manual content

Preserve manually curated text that is compatible with the new evidence. Refresh should be a targeted merge, not wholesale regeneration.
