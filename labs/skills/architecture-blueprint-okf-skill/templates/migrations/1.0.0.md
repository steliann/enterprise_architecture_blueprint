# Template Set 1.0.0

Initial canonical template set for Architecture Blueprint OKF 0.2.

Key conventions:

- root `index.md` and collection `index.md` files;
- unnumbered headings;
- public records omit standalone evidence sections;
- detailed provenance is stored under `.okf/`;
- `required-capabilities` includes functional and non-functional requirements;
- Consumers, Sources, and Technologies are maintained as top-level inventories with stable IDs.
